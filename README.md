# ChatEye 👁️

**ChatEye Mark 1 — A Computer Vision Project Built with PyTorch**

ChatEye is an experimental computer vision project that I built to explore image classification using Convolutional Neural Networks (CNNs).

The goal of this project is to develop my own vision model and improve it through experimentation, training, and future upgrades.

## 🧠 Features

- CNN-based image classification
- Built using PyTorch
- Six object categories:
  - Cat
  - Human
  - Pencil
  - Bottle
  - Phone
  - Laptop
- Real-time webcam classification using OpenCV
- Model training and weight saving

## ⚙️ Technologies Used

- Python
- PyTorch
- NumPy
- OpenCV
- Pillow

## 🏗️ Model Architecture

ChatEye Mark 1 includes:
- Two convolutional layers
- Batch Normalization
- ReLU activation
- Max Pooling
- Dropout
- A fully connected output layer

## 🚧 Current Status

**Mark 1 — Initial Experimental Version**

This project is still under development. Further improvements are planned for preprocessing, validation, dataset quality, and real-world classification performance.

## 🎯 Future Goals

- Improve classification accuracy
- Expand the dataset and number of classes
- Improve generalization to unseen images
- Experiment with different CNN architectures
- Develop future versions of ChatEye

## 💡 Motivation

I built ChatEye as part of my journey into Artificial Intelligence and Computer Vision. Rather than relying entirely on pretrained models, I want to learn how vision models work by building, testing, and improving my own.
